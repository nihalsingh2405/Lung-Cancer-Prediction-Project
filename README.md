# Lung-Cancer-Prediction-Project

## Project Overview
This project uses Machine Learning to predict the possibility of lung cancer based on patient health information and lifestyle factors.

The Support Vector Machine (SVM) algorithm is used to classify patient records based on the available dataset.

## Objectives
- Analyze patient health-related data.
- Perform data cleaning and preprocessing.
- Apply Support Vector Machine (SVM).
- Train and test the machine learning model.
- Evaluate model performance using accuracy and classification metrics.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- Support Vector Machine (SVM)

## Dataset
The dataset contains patient information such as:
- Age
- Gender
- Smoking habits
- Yellow fingers
- Chronic disease
- Coughing
- Chest pain
- Shortness of breath
- Other health-related factors

## Project Workflow
1. Import dataset.
2. Perform data preprocessing.
3. Explore and analyze the data.
4. Split data into training and testing sets.
5. Train the SVM model.
6. Evaluate model performance.
7. Predict results.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Python program:

```bash
python lung_cancer_prediction.py
```

This project is developed for educational purposes only. It is not intended for medical diagnosis or clinical decision-making.
